# 주소 시·도 축약형 인식 및 빈 결과 안내 설계

## 목표

사용자가 `서울 종로구 필운동 202`처럼 시·도를 일상적인 축약형으로 입력해도 주소를 추출한다. 추출 결과가 없을 때는 버튼이 무반응처럼 보이지 않도록 명확한 안내를 표시한다.

## 파서 동작

- 현재 지원하는 17개 시·도의 공식 명칭은 계속 인식한다.
- 각 시·도의 일반적인 축약형도 인식한다. 예: `서울`, `부산`, `세종`, `경기`, `강원`, `충북`, `충남`, `전북`, `전남`, `경북`, `경남`, `제주`.
- 추출된 `raw_text`와 `display_text`는 사용자가 입력한 표기를 그대로 보존한다. 공식 명칭으로 자동 변환하지 않는다.
- 기존 도로명·지번 패턴, 중복 제거, 별명 추출 동작은 변경하지 않는다.

## 화면 동작

- `/parse-text` 요청이 성공하고 주소가 한 개 이상이면 기존 목록을 표시한다.
- 요청은 성공했지만 주소가 0개이면 주소 목록 대신 `인식된 주소가 없습니다. 시·군·구와 번지를 포함해 입력해 주세요.` 안내를 표시한다.
- 네트워크 또는 API 오류가 발생하면 오류 메시지를 표시한다.

## 오류 처리

- API 비정상 응답은 응답의 `detail`을 우선 표시하고, 없으면 HTTP 상태 코드를 표시한다.
- 네트워크 예외는 기존 업로드 처리와 같은 방식으로 사용자에게 알린다.

## 검증

- 사용자가 제공한 서울 지번 주소 세 줄이 모두 추출되는 파서 회귀 테스트를 추가한다.
- 축약형과 공식 명칭이 모두 동작하며 기존 테스트가 유지되는지 확인한다.
- API가 동일 입력에 주소 세 개를 반환하는 테스트를 추가한다.
- 빈 결과 안내와 요청 실패 처리는 브라우저 테스트 또는 해당 JavaScript 동작을 검증할 수 있는 기존 테스트 방식으로 확인한다.
